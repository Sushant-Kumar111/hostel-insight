# 🏠 Hostel Insight

## 📌 Description

Hostel Insight is a web-based application designed to manage and analyze hostel-related information efficiently. It helps in organizing data, improving accessibility, and providing better insights for hostel management.

## 🚀 Features

* 📊 Data visualization and insights
* 🏢 Hostel information management
* ⚡ Fast and responsive UI
* 🔐 Secure configuration using environment variables

## 🛠️ Tech Stack

* React (Vite)
* TypeScript
* Firebase
* CSS

## 📂 Project Structure

* `src/` → Main application code
* `components/` → UI components
* `public/` → Static files
* `.env.local` → Environment variables (not included)

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Sushant-Kumar111/hostel-insight.git
   ```

2. Navigate to project:

   ```bash
   cd hostel-insight
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create `.env.local` file and add:

   ```
   VITE_API_KEY=your_key
   ```

5. Run the project:

   ```bash
   npm run dev
   ```
